# WattSurgeMatrix ("Can It Run?") — 2,000+ Page Programmatic SEO Appliance Surge & Power Station Runtime Engine

A zero-dependency, pure-HTML/CSS/Vanilla-JS Programmatic SEO (pSEO) matrix website targeting the **$65 – $115+ RPM Solar Generator, Portable Power Station (EcoFlow, Jackery, Anker SOLIX, Bluetti), and Home Backup Generator** vertical.

## What Is Built Out-of-the-Box (2,000+ Static HTML Pages)

1. **1 Master Directory & Interactive Load Stacker Homepage (`dist/index.html`)**
2. **102 Dedicated Appliance Running vs. Starting Surge & Battery Sizing Pages (`dist/appliances/[slug]/index.html`)**
3. **80 Dedicated Power Station & Generator 102-Appliance Compatibility Pages (`dist/generators/[slug]/index.html`)**
4. **1,560 Exact-Match "Can [Power Station] Run [Appliance]?" Pages (`dist/can-it-run/[unit]-run-[appliance]/index.html`)**
5. **230+ Head-to-Head Power Station & Generator Showdown Pages (`dist/compare/[unit-a]-vs-[unit-b]/index.html`)**
6. **20 Manufacturer Brand Hubs (`dist/brands/[brand]/index.html`)**
7. **4 Mandatory AdSense & E-E-A-T Compliance Pages (`/about/`, `/privacy-policy/`, `/terms/`, `/contact/`) + `/ads.txt` + Cloudflare Workers Static Assets Edge Configs**
